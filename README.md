# react-axios-users

A clean, modern React application that demonstrates how to fetch and display data from a REST API using **Axios**.


## Features

- Fetches a list of users from JSONPlaceholder API
- Proper loading and error states
- Responsive grid layout with beautiful user cards
- Clean and commented code — perfect for learning
- Built with Vite + React 18+ (fast development)

## Tech Stack

- React (Hooks: useState, useEffect)
- Axios (for HTTP requests)
- Vite (build tool)
- Plain CSS (no external libraries needed)

## Quick Start

```bash
git clone https://github.com/your-username/react-axios-users.git
cd react-axios-users
npm install
npm run dev
